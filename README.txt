
README — Ұзату той сайты (Kazakh, invitevip-style)

Файлтар:
- index.html  — басты бет
- style.css   — стильдер
- script.js   — жеңіл JavaScript
- audio-placeholder.mp3  — (placeholder файл жоқ) — орнына өз mp3 файлыңызды жүктеңіз
- README.txt  — осы нұсқаулық

Нұсқаулық — Tilda-ға қою (жылдам жол):
1) Tilda аккаунтына кіріңіз немесе тіркеліңіз: https://tilda.cc/
2) Жаңа жоба жасаңыз → «Create new site»
3) Жаңа бет қосыңыз → "Empty" (бос бет)
4) Блоктар арасынан "HTML" блокты таңдаңыз (әдетте "Other" дегенде) және ашыңыз.
5) index.html ішіндегі басты контентті (body ішін) көшіріп алып, сол HTML-блокқа салыңыз.
   - CSS: төмендегі екі жолдың бірін таңдаңыз:
     a) Тilda-да HTML-блок ішінде <style> ... </style> ретінде style.css мазмұнын қойыңыз; немесе
     b) Tilda-проектің Settings -> More -> Custom HTML/CSS бөліміне style.css-ті қойыңыз.
6) Карта үшін: көрсетілген Google Maps сілтемесін қолдану жеткілікті — егер iframe керек болса, Google Maps сайтынан Embed code алыңыз.
7) Музыка: егер mp3 бар болса, оны Tilda Files-қа жүктеп, audio тегіндегі src мәнін сол сілтемеге ауыстырыңыз. Немесе YouTube сілтемесін қойыңыз (iframe арқылы).
8) WhatsApp батырмасы автоматты түрде жұмыс істейді — тек нөмірді тексеріңіз: https://wa.me/77752219977
9) Тестілеңіз және жариялаңыз. Егер көмек керек болса, мен экрандық қадамдар жазып беремін.

Ескертпе: авторлық құқықпен қорғалған әндерді тікелей жүктемеуге немесе бөлісуге болмайды.
Осы пакет статикалық сайт ретінде жұмыс істейді — оны тікелей хостингке қойып (GitHub Pages, Netlify) немесе Tilda HTML-блоктарына қоюға болады.

Сұрақтар болса, жаз — мен орнатуға көмектесемін.
